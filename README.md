# CodeAlpha Basic Chatbot

A simple rule-based chatbot built using Python as part of my CodeAlpha internship.

## About the Project

This project is a command-line chatbot that responds to predefined user messages.

The chatbot accepts user input, processes it, provides an appropriate response, and keeps a record of the conversation.

## Features

- Responds to greetings such as hello, hi, and hey
- Answers simple questions
- Provides a help command
- Explains what Python is
- Handles unknown questions
- Accepts input regardless of capitalization
- Handles extra spaces in user input
- Maintains conversation history
- Allows the user to exit using `bye`

## Technologies Used

- Python
- Functions
- Conditional statements
- `while` loops
- `for` loops
- Lists
- String methods
- User input
